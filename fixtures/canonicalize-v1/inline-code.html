Sponsoring gas with a paymaster

A paymaster settles gas on behalf of an account, so a first-time user can send a transaction without holding the network's native token. The account still signs; only the fee moves.

Scope the policy as tightly as you can: by contract address, by function selector, and by a per-account spend ceiling. An open policy is a funded address that anyone on the internet can drain.
