Estimating gas for a user operation

A bundler quotes three limits for every user operation: verification gas, call gas, and pre-verification gas. Underquoting any of them drops the operation from the mempool rather than reverting it on chain, so the account never learns what happened.

Estimate against the same bundler you intend to submit to. Two bundlers can disagree about verification gas because they simulate with different state, and an estimate from one is not a promise from the other.

  • Verification gas covers signature checks and the paymaster's own validation.
  • Call gas covers the operation the account actually wanted to perform.
Quotes go stale as the base fee moves; re-estimate if a submission is delayed.
